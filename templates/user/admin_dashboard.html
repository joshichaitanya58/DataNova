DataNova Help & Quick Guide

Welcome to the Admin Control Panel! Here are quick shortcuts:

  • User Management: Click "See All Users" or "Add User" to manage accounts, change roles, or toggle Active/Inactive status.
  • Dataset Monitoring: Click "Show All Datasets" to inspect uploaded CSV/Excel files across all users.
  • System Activity: View live API invocation logs and export complete audit trails.
  • System Settings: Configure platform SMTP host, session timeouts, role defaults, and maintenance mode.
