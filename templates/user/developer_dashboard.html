Quick Start Integration Methods

Choose your preferred integration approach: Use the official Python SDK for automatic retry handling or consume the REST API directly.

OPTION A (RECOMMENDED) PyPI Package
DataNova Python SDK

Official SDK with automatic retries (GET by default, POST opt-in), typed errors, and one method per endpoint.

pip install datanova-sdk
from datanova_sdk import DataNovaClient, DataNovaAPIError

# api_key / base_url can also come from DATANOVA_API_KEY / DATANOVA_BASE_URL
try:
    with DataNovaClient(api_key="{{ api_key }}", base_url="{{ sdk_base_url }}") as client:
        # 1. Check system health
        print(client.health())

        # 2. Upload a dataset (CSV / Excel / JSON)
        dataset = client.upload_dataset("sales.csv")
        dataset_id = dataset["dataset_id"]

        # 3. Run the complete automated analysis
        analysis = client.run_auto_analysis(dataset_id)
        analysis_id = analysis["analysis_id"]
        print("Analysis status:", analysis.get("status"))

        # --- More SDK Methods & Functions below ---
        # 4. List datasets and preview schema & sample rows
        datasets = client.list_datasets()
        preview = client.preview_dataset(dataset_id)

        # 5. Exploratory Data Analysis (EDA)
        eda = client.run_eda(dataset_id, target_column="Revenue")

        # 6. Data cleaning: imputation + duplicate removal
        cleaned = client.clean_dataset(dataset_id, strategies={"Revenue": "median"}, remove_duplicates=True)

        # 7. Interactive charts & visualizations
        charts = client.generate_visualizations(dataset_id, chart_types=["histogram", "heatmap"])

        # 8. Analysis report & auto-generated Python code
        report = client.get_analysis_report(analysis_id)
        code = client.get_analysis_code(analysis_id)

        # 9. Ask a natural-language question about your data
        answer = client.ask_question("What is the total revenue trend?", dataset_id=dataset_id)

        # 10. Train supervised machine-learning models
        classification = client.train_classification(dataset_id, target_column="IsHighValue")
        regression = client.train_regression(dataset_id, target_column="Revenue")

        # 11. Async pipeline execution & status polling
        job = client.execute_pipeline(dataset_id, steps=[{"step": "clean"}, {"step": "eda"}])
        status = client.get_pipeline_status(job["task_id"])

        # 12. Developer API key management
        new_key = client.generate_api_key("MobileAppKey", environment="live", scopes=["datasets:read", "datasets:write"])
        client.revoke_api_key(new_key.get("key_id"))
except DataNovaAPIError as exc:
    print(f"DataNova error: {exc}")

Dataset Operations
Upload files, view indexed datasets, and inspect schema structures.
POST /api/v1/datasets/upload Upload Dataset
Scope: datasets:write

Uploads a CSV, Excel (.xlsx/.xls), or JSON dataset as multipart/form-data. Automatically calculates row/column counts, missing values, duplicates, and infers column semantic types.

Request Parameters (multipart/form-data)
Field Type Required Description
file File Yes CSV, Excel (.xlsx, .xls), or JSON file (Max 100MB)
Sample JSON Response (201 Created) 
{
  "success": true,
  "dataset_id": 101,
  "filename": "hotel_bookings.csv",
  "rows": 5000,
  "columns": 12,
  "status": "processed",
  "retention": "PROCESSED & PURGED"
}

Standard HTTP Status Codes & Response Handling

All DataNova API responses return standard HTTP response codes accompanied by a structured JSON payload containing success: true/false and detailed error messages.

HTTP Code Status Description & Suggested Action
200 / 201 OK / Created Request succeeded. Response body contains requested analytics payload or task identifier.
400 Bad Request Missing required parameter, unsupported file extension, or empty dataset.
401 Unauthorized Missing or invalid X-API-Key token header. Check active key in API Key Management.
403 Forbidden API key has been revoked, or lacks the required scope (e.g. attempting upload without datasets:write).
404 Not Found The requested dataset_id or analysis_id does not exist or belongs to another user.
429 Quota Exceeded Monthly limit of 2,000 API requests exceeded. Quota resets on the 1st of each calendar month.
